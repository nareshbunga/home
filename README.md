# Naresh Studio — Professional Light Homepage

This package is designed for `https://nareshstudio.com/`.

## Requested structure

The website root contains only:

- `index.html`

All supporting website files are under:

- `home/css/style.css`
- `home/js/main.js`
- `home/images/og-image.svg`
- `home/favicon/`

SEO files are also under `/home/` in this version as requested:

- `home/robots.txt`
- `home/sitemap.xml`

## Important

For standard search-engine discovery, it is normally better to place `robots.txt` and `sitemap.xml` at the domain root. They are included under `/home/` only to follow the requested folder structure.

Before publishing, replace the placeholder email and phone number in `index.html`.

Project routes used by the homepage:

- `/llm-guardrail`
- `/ollama`
- `/n8n`
- `/python`
- `/rag`
